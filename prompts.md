# Resume Studio — Project Brief

Create a modern, responsive, offline Resume Builder using beginner-friendly HTML, CSS, and JavaScript. Organize the site into `index.html`, `style.css`, and `script.js`.

The form should collect a full name, professional title, email, phone number, address, career objective, education, skills, experience, projects, and a profile photo. Let users add and remove multiple education, skill, experience, and project entries. Update the resume preview immediately as they type. Use a professional two-column resume design with a teal sidebar, circular profile photo, contact details, education, and skills in the sidebar, plus an introduction, experience, and projects in the main area. Make the page responsive for phones and desktop.

Add a `Download Resume as PDF` button that creates and downloads an A4 PDF directly in the browser, without an online service. Keep the app offline and local; do not add an account, server, external PDF library, or extra resume templates.

## Files

- `index.html` — form, preview, and repeatable entry templates.
- `style.css` — responsive form, resume, and print styling.
- `script.js` — live preview, photo selection, repeatable entries, and direct PDF download.

## Run

Keep the three files in the same folder and open `index.html` in a browser. Use the PDF button to download the resume. No installation or internet connection is required.
