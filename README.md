# Resume Studio

An offline resume builder that turns your details into a clean, printable resume. Fill in the form and see the preview update as you type.

**Live demo:** [Open Resume Studio](https://muskan7-tech.github.io/GenAI-/)

## Features

- Live resume preview as you edit your details.
- Add or remove education, skills, experience, and project entries.
- Select a profile photo from your device and preview it locally.
- Download an A4 PDF directly in your browser.
- Responsive layout for desktop and mobile screens.
- No account, server, API, or external PDF library required.

## Run locally

1. Download or clone this project.
2. Keep the project files together in one folder.
3. Open `index.html` in a current web browser.
4. Enter your details and choose **Download Resume as PDF** when ready.

The app works offline after the files are on your device. The PDF is created in the browser and downloaded locally.

## Project files

- `index.html` — resume form, preview, and reusable form sections.
- `style.css` — responsive styling and resume layout.
- `script.js` — live preview, repeatable sections, local photo preview, and PDF creation.
- `prompts.md` — original project brief and requirements.

## Privacy

Resume details and the selected photo stay in the browser on your device. The app does not send them to a server or store them after you close or refresh the page.
